# Changelog

## 0.1.0

Initial release.

- Path layout engine — text flows along SVG bezier paths (M, L, H, V, C, Q, S, T, Z)
- Pointer-reactive layout — repel, attract, orbit modes with spring physics
- SVG and Canvas renderers
- Accessible semantic layer (visually-hidden DOM node, aria-hidden on visuals)
- React components: `PathText`, `PointerText`
- Zero runtime dependencies
